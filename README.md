# Clinical Reasoning AI Agent

An educational AI-agent MVP built for the FlyRank FL-07 assignment.

## Purpose

Demonstrate an end-to-end agent workflow using:

- a real workspace data source;
- filesystem access;
- Code Execution;
- structured reasoning;
- report generation.

## Architecture

User
→ Agent
→ Synthetic Dataset
→ Evidence Analysis
→ Code Execution
→ Candidate Ranking
→ Report
→ Workspace Output

## Safety

This project uses synthetic educational data only.

It is not a medical diagnosis or treatment system.

## FL-07

The MVP demonstrates:

- end-to-end agent execution;
- live data/tool usage;
- documented development iterations;
- reproducible output generation.
